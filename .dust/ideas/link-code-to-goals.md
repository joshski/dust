# Link Code to Goals

It would be valuable to link code and/or tests to .dust files, especially goals.

## Benefits

- Understand code in terms of its goals
- Explore code or tests (especially high-level scenarios) that support specific goals
- Navigate from goals to their implementations
- See which goals are well-supported by tests vs. which lack coverage

## Possible Approaches

- Annotations or comments in code that reference .dust files
- A manifest file mapping code paths to goals
- Automated analysis that infers connections based on naming conventions or content
- Test file naming conventions that mirror goal file names
