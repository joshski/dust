# Standardize Principle Format

Establish a consistent structure for all principle files that encourages thinking through different aspects of each principle.

The format used in `readable-test-data.md` provides a good template:

1. **Opening statement** - A one-line summary of what the principle is about
2. **Why it matters** - Explains the reasoning and benefits
3. **In practice** - Concrete examples showing good vs bad approaches
4. **How to evaluate** - Criteria for determining if work supports the principle

This structure forces authors to think beyond just stating the principle. They must articulate why it matters, show practical application, and define how to measure alignment.

Current principles vary in format - some are a single paragraph, others have more structure. Standardizing would make principles more actionable and easier to reference when evaluating work.
