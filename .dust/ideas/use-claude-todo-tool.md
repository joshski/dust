# Use Claude's Todo tool in dust workflows

Claude Code has a built-in Todo list tool (TodoWrite) for tracking progress on multi-step tasks. When working through dust workflows that involve multiple steps (like implementing a task or following a goal), Claude could use this tool to:

- Track progress through workflow steps
- Show the user a clear view of what's been done and what remains
- Make it easier to resume work if interrupted

This would complement dust's existing planning system by providing real-time progress tracking during execution.
