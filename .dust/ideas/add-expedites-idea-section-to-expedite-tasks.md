# Add "Expedites Idea" section to expedite tasks

When decomposing an idea, the resulting task includes a "Decomposes Idea" section with a link back to the original idea. Expedite tasks don't have an equivalent "Expedites Idea" section, so there's no back-reference from the task to the idea it originated from.

Adding this section would make expedite tasks consistent with other idea transitions (decompose, refine, shelve) and allow `findAllWorkflowTasks` to track expedite tasks alongside other workflow task types.
