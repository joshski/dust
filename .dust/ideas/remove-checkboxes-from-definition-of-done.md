# Remove checkboxes from Definition of Done

Definition of Done sections currently use checkbox syntax (`- [ ]`) for list items. These should be plain list items (`-`) instead.

Checkboxes add visual noise without value — dust treats task completion as all-or-nothing (the whole task moves to `done/`), so per-item checkbox state is misleading. Agents don't benefit from the format distinction, and the checkboxes are never toggled by tooling.

This affects:

- Stock audit templates in `lib/audits/stock-audits.ts`
- Task templates generated by `bin/dust new task` and idea decomposition
- Example task content in tests
- Any documentation or facts referencing the checkbox format
