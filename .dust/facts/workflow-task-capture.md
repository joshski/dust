# Workflow Task Capture

Capture tasks are generated by `createIdeaTask(...)` and start from a title and description.

## Task Type Detection

Capture tasks are identified by the presence of a `## Task Type` section containing `capture`.

Example task structure:
- Title: `Add Idea: Smarter Error Recovery`
- Filename: `add-idea-smarter-error-recovery.md`
- Task type section: `## Task Type\n\ncapture`
- Definition of done expects one or more idea files plus open-question hygiene.

The title prefix `Add Idea:` is an optional convention for human readability but is not used for type detection.

## Parsing Existing Capture Tasks

`parseCaptureIdeaTask({ taskSlug })`:
- Returns `null` if the file is missing, has no `#` title, does not have `## Task Type` containing `capture`, or has no `## Idea Description` section.
- Returns `{ ideaTitle, ideaDescription }` for valid capture tasks.

Example output for `# Add Idea: Smarter Error Recovery`:

```ts
{
  ideaTitle: "Smarter Error Recovery",
  ideaDescription: "...",
}
```
