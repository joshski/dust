# Workflow Task Capture

Capture tasks are generated by `createIdeaTask(...)` and come in two modes.

## Add Idea Tasks

When `expedite` is omitted or `false`, title prefix is `Add Idea: `.

Example:
- Input: `{ title: "Smarter Error Recovery", expedite: false }`
- Task title: `Add Idea: Smarter Error Recovery`
- Filename: `add-idea-smarter-error-recovery.md`
- Definition of done expects one or more idea files plus open-question hygiene.

## Expedite Idea Tasks

When `expedite` is `true`, title prefix is `Expedite Idea: `.

Example:
- Input: `{ title: "Smarter Error Recovery", expedite: true }`
- Task title: `Expedite Idea: Smarter Error Recovery`
- Filename: `expedite-idea-smarter-error-recovery.md`
- Definition of done allows either direct implementation or decomposition into narrowly scoped tasks.

Expedite tasks can also be created as transition tasks via `createExpediteIdeaTask(...)`, which adds an "Expedites Idea" back-reference section linking to the source idea. These transition-style expedite tasks are tracked by `findAllWorkflowTasks` and `findWorkflowTaskForIdea`.

## Parsing Existing Capture Tasks

`parseCaptureIdeaTask({ taskSlug })`:
- Returns `null` if the file is missing, has no `#` title, does not use `Add Idea:` or `Expedite Idea:`, or has no `## Idea Description` section.
- Returns `{ ideaTitle, ideaDescription, expedite }` for valid capture tasks.

Example output for `# Expedite Idea: Smarter Error Recovery`:

```ts
{
  ideaTitle: "Smarter Error Recovery",
  ideaDescription: "...",
  expedite: true,
}
```
