## Idea Description

Make the agent settings dialog open in a page that:
* is addressable by URL
* hides the per-repository tabs
* allows http/ssh “git protocol” configuration per repository
* shows repositories in a table similar to the repositories dialog
* has a check box for each row
* allows batch operations when rows are checked
* shows the same repository list as in the repositories dialog (but moves the current repository to the top, with a different background colour)
* has column headings
