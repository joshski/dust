# Allow Multiple Idea Files in Add Idea Workflow

Update the "Add Idea" workflow task template to allow agents to create multiple idea files when research reveals distinct concepts.

## Background

The `createCaptureIdeaTask` function in `lib/artifacts/workflow-tasks.ts` generates content that says "create an idea file" (singular) at a predetermined path. This locks the agent into producing exactly one artifact. However, ideas often start vague and may reveal themselves as multiple distinct concepts during research.

## Implementation

Modify the task content generated by `createCaptureIdeaTask` (lines 324-349):

1. Change "create an idea file at `{path}`" to "create one or more idea files in `.dust/ideas/`"
2. Update the Definition of Done from "Idea file exists at {path}" to "One or more idea files are created in `.dust/ideas/`"
3. Remove the predetermined path constraint, allowing the agent to name files appropriately based on research findings
4. Keep the requirement for H1 titles matching the content, but don't require a specific title

This mirrors the flexibility already present in the "Build Idea" workflow which says "create one or more narrowly-scoped task files."

## Principles

- [Small Units](../principles/small-units.md) - supports splitting vague ideas into discrete, fine-grained units
- [Agent Autonomy](../principles/agent-autonomy.md) - gives agents flexibility to determine appropriate output
