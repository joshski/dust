# Build Idea: Add Coverage Exclusions Audit

Research this idea thoroughly, then create one or more narrowly-scoped task files in `.dust/tasks/`. Review `.dust/principles/` and `.dust/facts/` for relevant context. Each task should deliver a thin but complete vertical slice of working software.

## Idea Description

Add an audit which suggests considering any recent coverage exclusions and evaluating whether they should be reconsidered. If there is a way to avoid coverage exclusions by improving the code (e.g. decoupling) then the agent should use that opportunity to generate ideas for refactoring.
