## Definition of done

A `.gitignore` file exists that:
- Excludes `node_modules/` and other dependency directories
- Excludes build output and compiled files
- Excludes editor and IDE configuration files
- Excludes OS-specific files (`.DS_Store`, `Thumbs.db`, etc.)
- Excludes environment files containing secrets (`.env`, `.env.local`)
