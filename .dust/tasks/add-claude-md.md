# Add claude.md

Add a `claude.md` file to the repository root that describes the `.dust` directory structure and conventions. This enables simple prompts like "Work on the task foo" to work effectively without extensive context setup.

## Goals

- [Easy Adoption](../goals/easy-adoption.md)
- [Human-AI Collaboration](../goals/human-ai-collaboration.md)
- [Agent Agnostic](../goals/agent-agnostic.md)

## Blocked by

(none)

## Definition of done

- A `claude.md` file exists in the repository root
- The file describes the `.dust` directory structure (goals, facts, tasks, ideas)
- The file explains how to find and work on tasks
- The file references the prompts directory for common workflows
- Simple prompts like "Work on the next task" should be actionable after reading this file
